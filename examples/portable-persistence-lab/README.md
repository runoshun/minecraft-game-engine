# Portable Persistence Lab

A consolidated reference for Portable persistent scalar and Grid state. It replaces the separate v18 scalar and v19 Grid examples.

The program demonstrates:

- global persistent scalar state with reset and preserve schema policies;
- session-scoped persistent scalar state;
- global persistent Grid storage with an outside value;
- session-scoped persistent Grid storage;
- player-local input used to mutate persistent data;
- the normal persistent lifecycle generated by the compiler.

External team `lab_persist` supplies membership. **A** updates the global scalar/Grid data; **D** updates the session scalar/Grid data. The HUD exposes all values.

```bash
npm run compile:portable -- \
  --source examples/portable-persistence-lab/datapack/data/portable_persistence_lab/mcgame/main.ts \
  --namespace portable_persistence_lab \
  --output build/portable/portable_persistence_lab
```

Normal `portable/cleanup` preserves persistent data. Use the generated `portable/reset_persistent` or `portable/purge_persistent` functions for explicit persistence reset/teardown.
